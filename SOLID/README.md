# SOLID Exercises

This folder contains 10 Java exercises demonstrating the **SOLID design principles**.

## 📂 Exercises

| Folder | Demo Class  | Principle                               |
|--------|-------------|-----------------------------------------|
| ex01   | Demo01.java | Single Responsibility Principle (SRP)   |
| ex02   | Demo02.java | Open-Closed Principle (OCP)             |
| ex03   | Demo03.java | Open-Closed Principle (OCP) – cont.     |
| ex04   | Demo04.java | Dependency Inversion Principle (DIP)    |
| ex05   | Demo05.java | Liskov Substitution Principle (LSP)     |
| ex06   | Demo06.java | Liskov Substitution Principle (LSP) – cont. |
| ex07   | Demo07.java | Interface Segregation Principle (ISP)   |
| ex08   | Demo08.java | Interface Segregation Principle (ISP) – cont. |
| ex09   | Demo09.java | Dependency Inversion Principle (DIP) – cont. |
| ex10   | Demo10.java | All SOLID Principles Combined           |

## 🚀 How to Compile & Run Each Exercise

```bash
cd SOLID/ex01/src
javac *.java
java Demo01
```

Replace `ex01` / `Demo01` with the relevant exercise number.
